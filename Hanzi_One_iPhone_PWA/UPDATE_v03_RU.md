# Hanzi One 0.3 — обновление установленного приложения

Адрес остаётся прежним: https://daniil-dragon.github.io/hanzi-one/

1. На iPhone сохрани копию через **Ещё → Импорт / копии → Скачать резервную копию**. Не очищай данные Safari.
2. После успешных проверок объедини Pull Request версии 0.3 в `main` через **Merge pull request**. Повторно загружать файлы вручную не нужно.
3. Дождись успешной публикации GitHub Pages на вкладке **Actions**.
4. Закрой и открой приложение. Если появится кнопка **Обновить** вверху, нажми её после завершения текущей проверки. При переходе с 0.2 может потребоваться ещё один запуск.
5. Проверь **Версия 0.3** внизу страницы и **Все темы** на главной. Пройди «Знакомство и приветствия».
6. Проверь прежние карточки и избранное. Восстанавливать копию при сохранённом прогрессе не нужно.

## Что изменилось

- 10 оригинальных тематических уроков, 40 реплик диалогов с пиньинем и переводом, 60 упражнений: значение, пропуск, порядок слов и чтение.
- Разбор каждого ответа, порог зачёта 80%, история попыток и отдельный повтор ошибочных заданий. Повтор отдельных ошибок не заменяет полную проверку.
- Слова темы автоматически попадают в повторения после полной проверки. Можно добавить их раньше кнопкой в уроке.
- Колода теперь завершается и не запускает те же карточки бесконечно. Из журнала ошибок можно повторить именно проблемные слова.
- В прописях можно переключаться между знаками слова: например, написать и 你, и 好.
- Дневная цель 5, 10, 20 или 30 заданий; учитываются карточки, аудирование и задания тем.
- Копия формата `hanzi-one-v2` включает список HSK и словарный пакет; импорт проверяет данные до замены прогресса. Старые копии `hanzi-one-v1` поддерживаются. Если такая копия содержит HSK-прогресс, сначала загрузите HSK на новом устройстве, поскольку старый формат не включал сам список.
- Новая оболочка приложения кешируется целиком. Следующее обновление активируется кнопкой **Обновить**, чтобы не закрывать незавершённую проверку неожиданно.

## Границы этой версии

Тематический маршрут — начальные и отдельные базовые темы следующего этапа, а не полный учебник HSK 1–9. Аудио диалогов создаёт синтезатор устройства. Фонетическая оценка остаётся экспериментальной. Нет OCR, собственной видеотеки и полной русской базы HSK. Проверка Safari и микрофона на настоящем iPhone остаётся обязательной.

## Для разработки

```sh
npm ci
npm test
python tools/test_ru_pack.py
npx playwright install chromium
python -m http.server 8000
# В другом терминале:
npm run test:browser
```

Браузерная проверка также запускается в GitHub Actions. Для проверки реального списка HSK передайте `HANZI_HSK_FIXTURE` — путь к JSON исходного `hsk_vocabulary_compact.json`. После изменений корневых файлов выполните `python tools/build_release.py`: команда обновит папку приложения и ZIP из тех же исходников.
