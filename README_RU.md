# Hanzi One — инструкция (предварительная версия)

**Hanzi One** — бесплатное самостоятельное приложение для изучения китайского языка на iPhone в виде PWA. Язык интерфейса — русский, оформление — тёмное, иероглифы — упрощённые в словаре и курсах (каталог Канси показывает традиционные формы ключей). Платных разделов и регистрации внутри приложения нет.

## 1. Что готово

- Русский тёмный интерфейс с нижней навигацией.
- Уроки по 10 слов, проверка знаний с проходным порогом 80 % и фиксация результата.
- Карточки с интервальным повторением, ответы «Не помню / Трудно / Хорошо / Легко».
- 214 традиционных ключей Канси с ориентировочными русскими толкованиями.
- Свободные прописи пальцем на экране; при подключении интернета — попытка загрузить открытую Hanzi Writer для анимации и проверки порядка черт.
- Словарь и поиск по иероглифам, пиньиню и наличным русским значениям.
- Начальный набор слов (99 записей) с русским переводом встроен в приложение. Полный официальный по структуре экзаменационного списка HSK 3.0 2025/2026 (около 11 тыс. записей, без русских переводов) можно загрузить из открытого проекта `profesorm/hsk30` (CC BY 4.0). После загрузки список хранится на телефоне в IndexedDB.
- Синтез китайской речи доступен при наличии китайского голоса системы.
- Экспериментальная тренировка четырёх тонов по высоте голоса через микрофон. Результат приблизителен; это **не** полноценная фонетическая оценка по слогам и предложениям.
- Распознавание фразы в браузерах, в которых поддерживается соответствующий механизм. На iPhone/PWA функция требует проверки и может быть недоступной.
- Импорт своих карточек как TSV / CSV / JSON (например, из экспорта Quizlet).
- Экспорт и импорт резервной копии прогресса (JSON).

## 2. Что НЕ готово

Это **не полная копия шести приложений**, а рабочая техническая основа. Ещё нет: полного русского словаря 11 тысяч слов, курсов со всеми уроками/материалами HSK 1–9, собственных видео, аудиобиблиотеки носителей языка, OCR по фотографии, синхронизации между устройствами, достоверной проверки произношения и тонов в целых предложениях, гарантированной офлайн-анимации всех иероглифов. Продвинутые HSK 7, 8, 9 используют общий список HSK 7–9 (так устроена официальная программа), не выдуманные отдельные списки.

Все учебные режимы, которые есть, доступны бесплатно. Закрытые платные материалы чужих приложений НЕ копируются и доступ к их подпискам НЕ обходится.

## 3. Самый простой бесплатный способ установить с Windows на iPhone

1. Распакуй ZIP. **Не загружай ZIP как один файл** на сайт публикации — загрузи его содержимое.
2. Создай бесплатный аккаунт на [github.com](https://github.com), если его ещё нет.
3. Создай публичный репозиторий, например `hanzi-one` (Public, Add README не обязательно).
4. В репозитории нажми **Add file → Upload files**, выдели **все файлы из папки `hanzi_one`**, за исключением `make_data.py`, тестовых файлов и `preview.png` (эти служебные файлы в архив не входят). Нажми **Commit changes**.
5. Открой **Settings → Pages → Build and deployment**. Выбери **Deploy from a branch**, ветку **main**, каталог **/(root)** и сохрани. Публикация обычно занимает несколько минут.
6. Открой опубликованный адрес вида `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/hanzi-one/` **в Safari на iPhone**. URL появится в разделе Pages.
7. В Safari открой меню страницы → **Поделиться → На экран «Домой»**. Если предлагается вариант «Открывать как веб-приложение», включи его. Нажми «Добавить».
8. Запускай Hanzi One с домашнего экрана iPhone. На главной нажми **Загрузить HSK 1–9**, чтобы попробовать получить полный экзаменационный список. Для речи разреши микрофон.

GitHub Pages на публичном репозитории делает **код и веб-адрес доступными другим**, но **твой прогресс, карточки и записи микрофона в наш GitHub не загружаются**: они хранятся в браузере локально. Модуль распознавания речи, если устройство его предоставляет, может использовать внешние сервисы Apple. Для полной автономности понадобится доработка.

На iPhone 26.6.1 требуется проверить совместимость на реальном телефоне. Составитель протестировал интерфейс в настольном Chromium, но не в Safari iOS. Бесплатной разработческой подписки Apple для этого PWA не нужно.

## 4. Резервная копия

«Ещё → Импорт / копии → Скачать резервную копию». Сохрани JSON в файлы iPhone либо на Windows. Восстановление заменяет предыдущий прогресс. **Не очищай данные Safari до сохранения копии**.

## 5. Импорт карточек Quizlet и других приложений

Если сервис позволяет экспортировать твой учебный набор, скопируй его в текстовом виде:

```text
你好	здравствуй	nǐ hǎo
谢谢	спасибо	xiè xie
```

Затем «Ещё → Импорт / копии → Добавить карточки». Первое поле — китайское слово, второе — русский перевод, третье — необязательный пиньинь. Допускается TSV с табуляцией либо простая CSV. Автоматическое скачивание защищённой истории занятий из чужих сервисов не предусмотрено.

## 6. Лицензии и источники

- [profesorm/hsk30](https://github.com/profesorm/hsk30) — структурированные записи программы HSK 3.0 2025/2026, CC BY 4.0. Указываем происхождение записей и не представляем результаты своего теста как официальный HSK.
- [Hanzi Writer](https://hanziwriter.org/license.html) — исходный код MIT, данные иероглифов под Arphic Public License. Сами данные Hanzi Writer в архив не включены; веб-приложение при необходимости запрашивает их извне.
- Оригинальные тексты кратких грамматических объяснений и примерных русских толкований ключей подготовлены для этого проекта.
- Функции вдохновлены общими учебными задачами, но приложение не является продуктом Quizlet, HelloChinese, Chineasy, Radicals, Laoshi или trainchinese.

## 7. Запуск на Windows для проверки

Если установлен Python 3, открой Windows Terminal в папке с файлами и запусти:

```powershell
python -m http.server 8000
```

Затем открой `http://localhost:8000/` в браузере компьютера. Открытие `index.html` двойным щелчком **не рекомендуется**: некоторые функции хранения и загрузки данных могут быть ограничены. Для установки PWA на iPhone используй HTTPS-вариант GitHub Pages выше.

## 8. Нужные условия для готового полного продукта

Для полноценного приложения без подписок необходимо отдельно подготовить лицензированные или оригинальные материалы на 11 тыс. слов (русские переводы, примеры, грамматика, аудио), полноценный учебный план, локальные медиа и модель/алгоритм проверки китайских звуков и тонов, а затем проверить на реальном iPhone. Ни качество ASR, ни возможность надёжной синхронизации, ни полная функциональная паритетность с шестью коммерческими приложениями этой предварительной версией не заявляются.
