# Hanzi One 0.2 — обновление существующего сайта

Адрес приложения не меняется: https://daniil-dragon.github.io/hanzi-one/

## Сначала сохрани прогресс

1. Открой текущее приложение на iPhone, перейди **Ещё → Импорт / копии → Скачать резервную копию**.
2. Сохрани файл `hanzi-one-backup-....json` в «Файлы» на iPhone. **Не очищай данные Safari и не удаляй иконку приложения**.
3. В архиве `Hanzi_One_v02_GitHub.zip` находятся файлы новой версии. Разархивируй его на Windows.
4. Открой https://github.com/daniil-dragon/hanzi-one на вкладке Code.
5. Нажми **Add file → Upload files**, открой распакованную папку и перетащи **её содержимое**, а не саму папку и не ZIP. Если GitHub спросит об изменении существующих файлов — подтверди замену. Не удаляй `.nojekyll`.
6. Нажми **Commit changes**. Настройки Settings → Pages оставь `main` и `/(root)`.
7. Подожди завершения публикации на вкладке Actions; затем открой сайт в Safari. Если видна старая версия, закрой установленное веб-приложение полностью и открой его ещё раз; для обновления service worker иногда требуется повторный запуск.
8. Проверь нижний колонтитул **«Версия 0.2»**, карточки, «Ещё → Аудирование» и «Ещё → Избранное».
9. Если прогресс сохранился — **ничего не восстанавливай**. Восстановление нужно только если он действительно пропал.

Важное отличие: приложение по-прежнему является PWA. Оценка китайских тонов пока остаётся экспериментальной; Safari на iPhone ещё требуется проверить.

## Новое в 0.2

- Аудирование: короткие оригинальные фразы с произношением синтезатором устройства и проверкой перевода.
- Избранные слова (звёздочка рядом со словом) и поиск среди избранного.
- Редактирование русского перевода слов кнопкой `RU` в словаре. Исправления сохраняются и не теряются при повторной загрузке HSK.
- Журнал ошибок тестов и счётчик практики на день.
- Импорт пакета русских переводов из JSON в «Ещё → Импорт / копии»; словарь хранится в IndexedDB.
- Резервная копия включает избранное, ошибки, собственные переводы и импортированный словарь. Формат прежних копий v1 также поддерживается.
- Безопаснее обновляются файлы: service worker сначала пытается получить текущую версию сайта и использует кеш при отсутствии соединения.
- Тесты без русских переводов больше не засчитываются как полноценное понимание значения слов: проверка пиньиня остаётся тренировкой, но не даёт зачёт смыслового освоения.

## Не реализовано

Нет полноценного тематического курса HSK 1–9 с тысячами выверенных переводов и диалогов, полноценной фонетической оценки, распознавания через камеру и собственной библиотеки видео. Оригинальные платные материалы чужих сервисов не копируются. Эти задачи остаются в исходном техническом задании.

## Как получить больше русских переводов бесплатно

В архиве есть конвертер `tools/build_ru_pack.py`. Это добровольный дополнительный шаг для Windows:

1. Установи Python 3, если его нет.
2. Скачай открытый **Chinese → Russian** словарь в формате StarDict с https://freedict.org/downloads/ (файл вида `freedict-zho-rus-2025.11.23.stardict.tar.xz`). Уточни лицензию именно загружаемого архива. Он не включён в Hanzi One.
3. Открой PowerShell в распакованной папке с приложением и выполни:

   ```powershell
   python tools\build_ru_pack.py "C:\ПУТЬ\К\freedict-zho-rus-2025.11.23.stardict.tar.xz"
   ```

   Скрипт получает список HSK 3.0 из открытого проекта https://github.com/profesorm/hsk30 и сопоставляет китайские написания с переводами. Для работы необходимо интернет-соединение. Дополнительно можно передать свой файл списка через `--hsk ПУТЬ_К_JSON`.

4. Полученный `ru-pack.json` передай на iPhone через «Файлы», iCloud Drive или другой удобный способ.
5. В установленном Hanzi One открой **Ещё → Импорт / копии → Выбрать пакет переводов** и выбери JSON.
6. Проверь на знакомых словах правильность перевода. Автоматическое сопоставление неоднозначно: одно слово может иметь несколько значений, а часть записей не найдётся. Такой импорт — расширение словаря, **не готовый выверенный курс**.

Сам словарь необязательно загружать в публичный репозиторий. Он может оставаться только в локальном хранилище твоего телефона. Переводы из сторонних словарей имеют собственные лицензионные условия (https://www.wikdict.com/page/download/).
